# Workflow PDF auf iPhone und iPad (kostenlos)

Für Freunde ohne Android oder Windows. Es gibt noch keine App im App Store.
Die Webversion läuft im Browser und bleibt auf dem Gerät.

## So geht es

1. Auf dem iPhone oder iPad **Safari** öffnen.
2. Diese Adresse aufrufen: <https://lausiklauskn-png.github.io/Workflow-PDF/>
3. Unten (iPad: oben rechts) auf **Teilen** tippen, das Viereck mit dem Pfeil nach oben.
4. **„Zum Home-Bildschirm“** wählen, dann **„Hinzufügen“**.
5. Ab jetzt Workflow PDF über das neue Symbol starten.

## Gut zu wissen

- Die Dokumente liegen im Speicher dieser Web-App auf dem Gerät. Sie gehen nicht ins Netz.
- **Sicherung machen:** Wer Safari-Daten löscht, löscht auch die Dokumente.
  Darum ab und zu in den Einstellungen eine Sicherung speichern, zum Beispiel in „Dateien“.
- Was fehlt gegenüber der Pro-App: der verschlüsselte Ordner als Hauptablage und die
  Übernahme von Dateien über „Öffnen mit“.
- Beim ersten Start einmal mit Internet öffnen. Danach geht das meiste auch ohne Netz.
