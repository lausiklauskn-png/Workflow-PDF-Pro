Claude Code und Codex verwenden denselben Release-Workflow und dieselbe
dauerhafte Workflow-PDF-Pro-Signieridentität. Jeder Arbeitsdienst benötigt eine
eigene gültige GitHub-Verbindung mit den dokumentierten Repo-Rechten.

Aktuell ist noch keine native reguläre App ausgeliefert. Ein gespeicherter
Workflow, ein Git-Push oder eine bestandene Prüfung mit synthetischer APK belegt
keine erfolgreiche Veröffentlichung oder Geräteinstallation.
